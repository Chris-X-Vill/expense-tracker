# Ledger — Expense Log & Financial Planner

A lightweight, privacy-first personal expense tracker, budget overview, and debt payoff planner that runs entirely in the browser with zero external runtime dependencies.

## Features

- **Expense & Income Log:** View transactions by day, week, or month, filter by type, and search across notes and categories.
- **Monthly Overview:** Track monthly cash flow, progress toward a monthly savings goal, category spending breakdowns, and highest-interest debt priorities.
- **Debt Payoff Planner:** Manage balances, APRs, and minimum payments with automatic payoff time and interest estimates. Recording a debt payment automatically logs an expense under *Debt payments*.
- **Custom Categories:** Add, edit, color-code, or remove custom expense and income categories.
- **Local Privacy & Backups:** All data stays in `localStorage` in your browser, with one-click JSON backup export and restore.

## Running Locally

Simply open `index.html` in any modern web browser, or serve the folder with a local static server:

```bash
npx serve .
```
